# 新瑪奇武器聚能查詢

一個純靜態的單頁查詢工具，用來查詢新瑪奇武器聚能開放材料。

## 功能

- 依武器分類、Rank、開放階段查詢材料。
- 支援武器分類搜尋與目前材料清單搜尋。
- 顯示 S / A / B Rank 與階段 1-9 的材料需求。
- 點擊材料道具即可複製道具名稱。
- 內建經驗值補足計算，支援 3星、2星、1星、0星聚能素材經驗加總。
- 介面使用接近遊戲聚能視窗的紙面、金框與深色邊框風格。
- 支援亮色 / 暗色系切換，並會記住上次選擇。
- 資料來源整理自 `聚能開放_材料資料.xlsx`，並輸出為 `weapon_data.json` 供網頁讀取。



## 更新資料

若 Excel 內容更新，重新從 `聚能開放_材料資料.xlsx` 轉出 `weapon_data.json` 後，頁面會讀取最新資料。武器分類以工作表為單位，Rank 使用 S / A / B，階段使用 1-9。
